CSS Selectors Demo

Yeh page saare CSS Selectors ko demonstrate karta hai.

1. Universal Selector

Universal selector poore page ke saare elements ko select karta hai.

2. Element Selector

Yeh ek paragraph hai — element selector se select hua.

Yeh doosra paragraph hai — same element selector.

3. Class Selector ( .classname )

Yeh class="highlight" wala paragraph hai.

Yeh bhi same class se select hua hai.

Yeh class="warning" wala paragraph hai.

4. ID Selector ( #idname )

Yeh id="special-para" wala paragraph hai. ID ek hi baar use hoti hai.

5. Group Selector ( h1, h2, p )

Yeh h3 group selector se style hua.

Yeh h4 bhi group selector se style hua.

Yeh paragraph bhi group selector mein hai.

6. Descendant Selector ( div p )

Yeh paragraph div ke andar hai — descendant selector se select hua.

Yeh bhi div ke andar wala paragraph hai.

Yeh paragraph div ke bahar hai — select nahi hua.

7. Child Selector

Yeh direct child paragraph hai — child selector se select hua.

Yeh span ke andar hai — direct child nahi — select nahi hua.

8. Adjacent Sibling Selector ( h3 + p )

Yeh h3 hai

Yeh h3 ke bilkul baad wala paragraph hai — adjacent sibling select hua.

Yeh doosra paragraph hai — select nahi hua.

9. General Sibling Selector

Yeh h3 hai

Yeh pehla sibling paragraph hai — select hua.

Yeh doosra sibling paragraph bhi — select hua.

Yeh teesra bhi select hua — general sibling sab ko pakadta hai.

Yeh link target attribute nahi hai.
